About the project

About the demo

Phishing Detector · three fictional emails in an isolated test database.

Filter messages that need review, open a fictional email and examine the detected signals.

I wanted to build a cybersecurity project that could be useful day to day. Phishing Detector started with a single email file analyzed in the terminal. Then I wanted to connect it to my mailbox so I would not have to import everything manually.

It can now analyze Outlook messages and explain what caught its attention, such as a link pointing somewhere other than the address shown. On request, it adds categories directly in Outlook to help find messages that need review and promotional emails.

I tested the labels on my own mailbox. A flagged message is not necessarily fraudulent, though, and some threats can slip through. Tests using fictional emails are not enough to establish real-world reliability; the new Windows version also still needs testing with a real account.
