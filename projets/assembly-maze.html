About the demo

            
JavaScript simulation · the original project is written in assembly.

          

          

            
I wanted to get a better grasp of x86-64 assembly by building something. I chose a small maze: move a character, run into walls and find the way out.

            
The program runs in a Linux terminal without the C library. Every move involves the player’s position, memory and branching. The original game uses ZQSD followed by Enter, R to restart and X to quit. Automated tests include complete playthroughs.

            
The interactive preview uses the same map in JavaScript so you can try it here with the arrow keys or WASD. The original project is written in assembly and runs on Linux, including Ubuntu or WSL.
