Addblock

Reduce unwanted ads and pop-ups, with the option to pause protection on individual sites.

  • JavaScript
  • Manifest V3
  • Chrome / Edge

See it in action

Addblock running on its local test page · original French interface · no advertising servers contacted.

The sample ad is visible while protection is paused and disappears when protection is enabled. A test click then tries to open an unwanted tab, which is blocked. Useful content stays visible.

I started this project because I was tired of intrusive ads and windows opening whenever I clicked something. I wanted to build an extension I could actually use in my own browser.

Addblock blocks advertising requests, hides some ad placements and limits pop-ups. You can pause it on individual sites. It can be installed manually in Chrome or Edge.

It does not block everything: websites change, rules need updating, and some sites detect the extension. It is not available in browser extension stores yet.
