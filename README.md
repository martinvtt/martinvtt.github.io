# Martin Vitte — Portfolio

Static portfolio built with HTML, CSS and JavaScript. Project demonstrations use
fictional data. Includes six color themes, project pages and English/French CV previews.
The CV documents are provisional and will be replaced with the final versions.

## Preview locally

```sh
python3 -m http.server 8770 --bind 127.0.0.1
```

Open http://127.0.0.1:8770. No build step or dependencies are needed.

## GitHub Pages

Repository: `martinvtt/martinvtt.github.io` (public).
In Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**.
After deployment succeeds, the intended address is https://martinvtt.github.io/.
This README does not confirm that deployment has happened.

Only public site assets belong here. Do not add application databases, credentials,
private documents or installers. Contact addresses are deliberately public.
